All Books: degree distribution

Degree is the number of distinct character neighbors in the undirected interaction graph. Isolates are included. The horizontal axis is k + 1 so degree zero remains visible on a logarithmic axis.

111 nodes · 759 distinct edges · 0 isolates · average degree 13.68 · density 0.1243

P(k) is the fraction of characters with degree k. The optional power-law reference uses P(k) ∝ k⁻γ for k ≥ 1, excludes isolates, and is scaled to the observed positive-degree mass; it is an adjustable reference shape, not a fit. The binned view uses width-one bins for k + 1 = 1…7, then doubling integer bins; each count is divided by the bin width.
